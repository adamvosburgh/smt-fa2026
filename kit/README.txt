This folder is the Simulations, Models, Twins kit. It gives your coding agent the course's context.
Unzip it somewhere you can find it again, such as your Documents folder.
Open the smt-kit folder in VS Code (File > Open Folder).
Start your coding agent from inside this folder, so it reads AGENTS.md.
Then go to Tutorial 4 at simmodeltwin.net/tutorials/04-notebook-to-sandbox/ and follow it from there.
